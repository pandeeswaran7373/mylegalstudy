Civil Procedure Code, 1908

A smart, simplified guide to CPC structure and jurisdiction

The "Smart" Intro to CPC Structure

The Code of Civil Procedure (CPC) is divided into two main parts. The sections provide the substantive framework (jurisdiction, powers), while the Orders/Rules provide the step-by-step procedural machinery to implement those sections.

THE BODY OF THE CODE

158 Sections

Divided into 11 Parts.

Nature: Substantive. Can only be amended by the Parliament/Legislature.

THE FIRST SCHEDULE

51 Orders

Each Order contains multiple Rules.

Nature: Procedural. High Courts can amend rules based on local needs.
